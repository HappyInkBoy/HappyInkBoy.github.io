## Project Linear Algebra Calculator

[[Try LAC here](https://happyinkboy.github.io/lac/calculator.html)]
*  Using Python embedded into a web browser (thank you Brython library!), with some typical HTML / javascript / CSS around.
*  You can perform matrix operations common in linear algebra, along with various functions on them. Such as the determinant, trace, transpose, etc...
*  You can also input a system of equations to be solved.
